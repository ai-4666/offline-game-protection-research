# Selective Diversification and Behavioral Observation

2026-10-28 · Public research record. Experimental sources and binaries remain private.

## Results

A generator specialized to one game-logic sample split its operations into stages and varied data representations and dispatch states by seed. It cannot transform arbitrary games or C functions. Two seeds produced different binary SHA-256 values, which alone do not establish protection. The three logic variants agreed on 1,003 boundary and random inputs.

Two evaluators without source or conversation history examined the unprotected binary and seed 101 using REA/Ghidra. Each produced an independent program that matched another 260 inputs generated by the primary investigator. The reconstruction from seed 101 also matched the seed 202 binary on those same 260 inputs. The recovered behavior therefore applied to another build without analyzing that build's machine code. This does not prove agreement for every input.

Access restrictions were instruction-based, with no OS file isolation. Each condition had one attempt by a different evaluator, running concurrently on the same host. Reported durations were approximately 107 and 100 seconds, but contention, workflows, and trial-and-error differed, so the times cannot establish protection strength or a timing advantage. The targets were single logic executables, not complete games.

## Game costs and developer impact

The same small terminal game used 200 enemies and 6,000 updates per run, with seven randomly ordered runs per variant. The table reports medians across run medians and run 95th percentiles. In-memory text-frame generation was included; input, actual output, and graphics display were excluded. These are not FPS. Scripted final screens and final states agreed.

| Build | Median update time | Median 95th percentile |
| --- | ---: | ---: |
| Unprotected | 0.90 μs | 1.39 μs |
| Seed 101 | 1.76 μs | 3.23 μs |
| Seed 202 | 1.75 μs | 2.66 μs |

![Terminal-game experiment](figures/diverse-performance.png)

With GCC 15.2.0 `-O2 -g`, median compile/link times across five runs were 171.8 ms for baseline, 189.3 ms for seed 101, and 193.4 ms for seed 202. Separate generation time was excluded. These small-project figures do not generalize to developer adoption effort. GDB breakpoints worked in all three builds, but protected builds stopped in generated C source. Automatic original-source mapping, difficult debugging, real-engine integration, and player compatibility were not measured. One combined measurement of generation and two executable builds was approximately 408 ms.

## Behavioral observation

A separate input-output-only experiment, with prior knowledge of the output layout and candidate formula family, found a formula after 51 queries that matched another 300 inputs. The result depends heavily on prior knowledge and a small hypothesis space; it does not measure general-game reconstruction cost. It illustrates that observable behavior can reveal information independently of code representation.

**Conclusion:** this prototype did not prevent REA reconstruction without source disclosure. The recovered behavior also applied to another seed, and update costs increased. This does not invalidate every form of obfuscation or diversification. See the [foundations report](FUNDAMENTAL_ANALYSIS.md) for the threat model and theoretical limits.
